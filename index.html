Синхронизация

Записи и продукты будут одинаковыми на телефоне и на ПК. Данные хранятся в приватном gist в твоём GitHub. Ключ нужно вставить один раз на каждом устройстве.
  1. Открой создание ключа на GitHub (галочка gist уже стоит).
  2. В Expiration выбери No expiration, внизу нажми Generate token.
  3. Скопируй ключ (начинается с ghp_) и вставь сюда. Тот же ключ подойдёт для второго устройства.

Распознавание этикеток

Для точного распознавания нужен бесплатный ключ OCR.space. Фото таблицы отправляется на их сервер. Без ключа распознавание идёт прямо на телефоне, но заметно хуже: путает запятые.
  1. Открой страницу бесплатного ключа, впиши почту и нажми кнопку регистрации.
  2. Ключ придёт письмом. Скопируй его и вставь сюда.
