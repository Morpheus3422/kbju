# Ascend

Еда, спорт и план дня в одном приложении: калории и БЖУ со сканером штрихкодов, тренировки с прогрессом, задачи и расписание. Работает в браузере на iPhone и ПК, ставится на экран «Домой».

Данные о продуктах — Open Food Facts. Сканер — html5-qrcode (Apache 2.0, см. LICENSE-html5-qrcode).
